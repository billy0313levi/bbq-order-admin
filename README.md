### cloudToolsAdmin是什么
cloudToolsAdmin是基于uni-app/uniCloud开发的云端一体扫码点餐后台模板。

### 为什么选择我们
1. 开发成本低，无论是给企业自用或做项目外包均可节省大量时间;
2. 前后端语言均为js，无需额外掌握php/java等后端语言;
3. 基于uniCloud，无需考虑服务器配置，无运维成本，最重要的是uniCloud **完全免费**！

### 项目构成
 - [前端](https://ext.dcloud.net.cn/plugin?id=17469)基于uni-app开发
 - [服务端](https://ext.dcloud.net.cn/plugin?id=7822)基于[uniCloud](https://ext.dcloud.net.cn/plugin?id=5043)开发
 - 同时均使用了[@VK大佬](https://ext.dcloud.net.cn/publisher?id=164406)提供的开发框架，感谢大佬！

**特别提醒！[服务端](https://ext.dcloud.net.cn/plugin?id=7822)不含任何云函数！**

**特别提醒！前后端云函数均包含在[前端](https://ext.dcloud.net.cn/plugin?id=17469)工程中！需要单独购买，否则无法正常使用！**
