# 点餐小程序后台面板

基于 uni-app / uniCloud 开发的云端一体扫码点餐系统「管理后台」，与「点餐小程序前台」配套使用。后台与前台共用同一套云函数与云数据库，商家在后台维护的数据（菜品、分类、桌号）会实时同步到小程序前台，前台产生的订单也会实时回流到后台，实现前台点餐、后台接单的完整闭环。

## 技术栈

- 前端框架：uni-app（Vue2）+ uView / element 风格管理界面
- 后端：uniCloud（阿里云），云函数 + 云对象 + JQL
- 底层框架：VK（uniCloud 开发框架）

## 快速开始

1. 使用 HBuilderX 打开本项目，确认已关联 uniCloud 服务空间（阿里云）。
2. 在 `uniCloud` 目录右键上传全部云函数/云对象，并初始化数据库（导入项目内的数据库 Schema 与数据）。
3. 运行到浏览器（H5）即可访问后台，地址形如 `http://localhost:8080/admin/`。
4. 使用管理账号登录（账号由后台「系统管理-用户管理」维护）。

## 核心功能模块

以下四大模块与小程序前台直接相关：前台展示的数据由后台维护，前台的运营动作（下单、付款）也会反馈到后台。

### 订单管理

对应页面：`pages/order/order.vue`（列表 + `orderDetail.vue` 详情）

前台用户扫码点餐并完成支付后，订单实时进入后台订单列表，商家在此完成接单与收尾操作。

- **订单列表**：展示订单号、桌号、买家昵称、应收/实收/优惠金额、支付方式（微信/支付宝/余额）、订单状态、下单时间。
- **多条件筛选**：支持按下单时间区间、订单状态、支付方式、桌号（模糊）进行筛选。
- **订单详情**：抽屉式展示购买者信息、订单状态、桌号、金额明细（应收、实收、包装费、配送费、优惠）、支付方式、买家备注、收货信息，以及所购商品的明细表格（商品图片、名称、单价、数量、退款数量、退款金额）。
- **状态流转**：订单状态统一为 `0 待支付 → 1 制作中 → 2 已完成 / 3 已取消`。
  - **标记完成**：订单完成后自动释放桌台为空闲状态。
  - **取消订单**：取消后自动释放桌台为空闲状态。
  - 已完成 / 已取消的订单不允许再修改状态。

### 菜品管理

对应页面：`pages/goods/goods.vue`

管理小程序前台菜单中展示的全部菜品。

- **菜品列表**：展示商品图片、所属类目、商品名称、价格区间（取默认 SKU 价格）、销量、是否上架、添加时间。
- **添加 / 编辑菜品**：
  - 基本信息：商品图片、轮播图（最多 6 张）、商品名称、商品描述、所属类目、起售数量、初始销量。
  - 商品配置：是否上架、是否禁用会员价、推荐度。
  - **SKU 规格**：通过规格编辑器配置规格组（如 大杯/中杯/小杯）及规格值，为每个 SKU 设置售价与会员价。
- **上架 / 下架**：列表开关直接调用云函数 `sys.goods.sys_updateIsOnSale` 切换，前台菜单即时生效。
- **估清（沽清）**：对单个商品或批量勾选商品一键加入沽清列表，前台售罄后自动下架该商品；支持查看 SKU 详情。

### 分类管理

对应页面：`pages/category/category.vue`

维护小程序前台菜单的类目结构，菜品必须归属于某个分类后才会在前台展示。

- **分类列表**：展示分类图片、类目名称、排序、是否启用、添加时间。
- **添加 / 编辑分类**：设置分类图片、类目名称、排序值（值越小越靠前）、是否启用。
- **启用 / 禁用**：开关切换后前台菜单即时更新，禁用分类后其下菜品不再展示。
- **整类估清**：一键将该分类下所有菜品批量加入沽清列表，适合售罄场景快速下架。

### 桌号管理

对应页面：`pages/table/list.vue`（列表）、`add.vue`（新增）、`edit.vue`（编辑）

管理门店实体桌台，每个桌台对应一张点餐小程序码，前台顾客扫码即可进入对应桌台的点餐页。

- **桌号列表**：展示桌号、扫码场景值、点餐二维码图片（可点击预览）、容纳人数、桌台状态（空闲 / 使用中）、创建时间。
- **新增桌号**：填写桌号（如 A01、B02）与容纳人数，提交时自动调用云对象 `tableQrManager.generate` 生成该桌的专属小程序码（绑定桌号场景值），并实时预览。
- **编辑桌号**：可修改桌号、容纳人数与桌台状态，支持重新生成小程序码。
- **删除桌号**：支持单条删除与批量删除。
- **导出**：一键导出桌号列表为 Excel 文件。
- **状态联动**：前台订单「已完成 / 已取消」时，后台自动将该桌台释放为空闲。

## 与小程序前台的数据关系

| 后台模块 | 数据库集合 | 前台关联 |
| -------- | ---------- | -------- |
| 分类管理 | `category` | 前台菜单左侧分类栏、菜品归类 |
| 菜品管理 | `goods` | 前台菜单菜品列表、详情、加购、估清展示 |
| 桌号管理 | `table` | 前台桌台扫码入口、点餐页桌号标识 |
| 订单管理 | `order` | 前台下单 / 支付后生成订单，状态实时同步 |
